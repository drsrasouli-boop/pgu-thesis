## 🌟 دربارهٔ پروژه

**pgu-thesis** یک قالب رسمی و کامل لاتک برای نگارش **پروژه، پایان‌نامه و رساله** در **دانشگاه خلیج فارس** است.
این مخزن شامل فایل‌های سبک، فونت‌های ضروری، مستندات و نمونه‌های آماده است تا دانشجویان بتوانند بدون دغدغهٔ تنظیمات، روی محتوای علمی خود تمرکز کنند.

> ✨ طراحی مدرن · ساختار استاندارد · پشتیبانی کامل از فارسی · سازگار با XeLaTeX

## 🌟 About

**pgu-thesis** is an official, complete LaTeX template for writing **projects, Master's theses, and PhD dissertations** at **Persian Gulf University**.
It ships with style files, required fonts, documentation, and ready-to-use samples — so you can focus on your research, not on formatting.

> ✨ Modern design · Standard structure · Full Persian support · XeLaTeX-ready

## 🚀 Quick Start | شروع سریع

<div dir="rtl" align="right">

### ۱️⃣ نصب توزیع تک‌لایو (TeX Live)

آخرین نسخهٔ **TeX Live** را از آدرس زیر دانلود و نصب کنید:

🔗 <https://www.tug.org/texlive/windows.html>

### ۲️⃣ نصب ویرایشگر TexStudio

ویرایشگر **TeXstudio** را از آدرس زیر دریافت کنید:

🔗 <https://www.texstudio.org/>

### ۳️⃣ دریافت قالب و فونت‌ها

قالب، فونت‌های ضروری و بستهٔ کامل فونت‌ها از این مخزن قابل دریافت است:

🔗 <https://github.com/drsrasouli-boop/pgu-thesis>

</div>

<div dir="ltr" align="left">

### 1️⃣ Install TeX Live

Download and install the latest **TeX Live** distribution:

🔗 <https://www.tug.org/texlive/windows.html>

Get the **TeXstudio** editor:

🔗 <https://www.texstudio.org/>

### 3️⃣ Get the Template & Fonts

Download the template, required fonts, and full font bundle from this repository:

🔗 <https://github.com/drsrasouli-boop/pgu-thesis>
